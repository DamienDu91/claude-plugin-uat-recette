# Contribuer

Issues et pull requests bienvenues, en français ou en anglais.

- Ouvrir une issue avec le gabarit : site type (marchand ou non), plateforme, navigateur utilisé, ce qui était attendu et ce qui s'est passé.
- Les skills sont des instructions pour Claude : garder un style impératif, des règles vérifiables, et ne jamais assouplir les garde-fous (porte staging, aucun mot de passe saisi, approbation explicite avant écriture).
- Ne jamais committer d'URL internes, de données clients ou d'identifiants. Les exemples utilisent `exemple.fr`.
- Mettre à jour `CHANGELOG.md` et la version dans `.claude-plugin/plugin.json`.
